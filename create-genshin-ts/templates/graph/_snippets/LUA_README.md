## Client Lua

This project has node graphs only. To add client control scripts (Lua) later, follow [Adding Lua to an existing project](https://gsts.moe/doc/lua#add-lua): create `src/lua/tsconfig.json`, exclude `src/lua` in the root `tsconfig.json`, then write your first `g.clientControlScript` entry. A new project created with the "Node graphs + Lua" template shows the finished layout.
