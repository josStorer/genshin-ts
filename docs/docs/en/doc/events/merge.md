# Multi-entry and Merge

- Entries with the same ID merge into one graph.
- After merging, graph variables you declare must have unique names; a duplicate name is an error, so rename one. Internal variables generated by gsts are named per file; only `__gsts_stage`, used by `stage`, is shared.
- Files merged into one graph cannot all call the same `gstsServer` function that starts a timer: once merged, its callback would run several times per trigger, so the build fails. Call it from only one of the files, or give the files different graph IDs.
- `entries` controls which files are compiled.
- To disable injection temporarily, set `id` to a non-existent value.
