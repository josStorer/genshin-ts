# 作用域划分

## 顶层作用域（编译期）

- 可读文件、用 npm 库、做预计算。
- 注意：顶层代码可能会执行多次。
- 顶层 `let` 在一个事件里被赋上运行时的值、又在另一个事件里读取，会形成跨事件的数据连线。官方风险检查会提示“跨逻辑子图的运算流连线”，数据传递会出错，所以编译直接报错，ESLint（`gsts/no-outer-graph-assignment`）也会警告。跨事件共享数据请用节点图变量（`f.set` / `f.get`、`stage.set`），或在当前事件里重新计算。

## 节点图作用域（运行期）

- 仅支持可编译的 TS 子集。
- `g.server().on(...)` 与 `gstsServer*` 内的代码会被编译。
- 其他普通函数在编译期执行：可以传字面量做预计算，也可以接收 `f` 调用节点函数；但不能对游戏运行时的值做 JS 运算（`*`、`+`、`<`、`Number()` 等），否则构建会报错并提示改用 `gstsServer` 开头的函数。

## 技巧

- `raw(...)` 可让编译器忽略表达式，保留 JS 语义。
- `stage.set` 可作为全局变量使用。
