# 定时器

- `setTimeout` / `setInterval` 单位为毫秒。
- 0 秒的定时器在游戏里不会触发。直接写的延时小于 10ms（包括不写延时）时按 10ms 处理；运行时计算出来的延时不做处理，可能为 0 时回调可能永远不执行。
- 编译器自动生成名称池，规避同名冲突。定时器名末尾带节点图 ID 的后 5 位（例如 `__gsts_timeout_3_0_41921`）：定时器按名字区分，触发时会通知实体上挂载的所有节点图，加上图 ID 后，挂在同一实体上的不同图不会互相重启或误触发。
- `// @gsts:timerPool=4` 可覆盖池大小。
- 在定时器回调中，捕获到的定时器句柄可直接用于 `clearTimeout/clearInterval`（包括清理非自身句柄）。
- `setInterval` 过高频率（<=100ms）会警告。
